## Shot Controls (PS5 / Xbox)

### How to Execute Each Shot Type

| Shot Type | PS5 Control | Xbox Control | When to Use |
|-----------|-------------|--------------|-------------|
| **Standing Jump Shot (Go-To)** | Hold □ or R-Stick ↓, release at peak | Hold X or R-Stick ↓, release at peak | Catch-and-shoot, open looks |
| **Pull-Up Jumper** | Move L-Stick + Hold □ | Move L-Stick + Hold X | Off the dribble, stop-and-pop |
| **Step-Back Shot** | Hold L-Stick away from basket + tap □ | Hold L-Stick away + tap X | Create separation, mid-range |
| **Spin Shot** | Moving laterally, double-tap □ | Moving laterally, double-tap X | Wrong-foot trailing defender |
| **Hop Jumper (Fade)** | Post up (L2) + tap □ while moving | Post up (LT) + tap X while moving | Fadeaway from post, mid-range |
| **Post Fade** | Post up (L2) + R-Stick away from basket | Post up (LT) + R-Stick away from basket | Back-to-basket fadeaway |
| **Post Hook** | Post up (L2) + R-Stick toward basket (off-hand side) | Post up (LT) + R-Stick toward basket | Sky hook, close range |
| **Post Hop Shot** | Post up (L2) + tap □ + direction | Post up (LT) + tap X + direction | Hop step into shot |
| **Quick Shot (Catch & Shoot)** | Hold L2 while receiving pass → immediately □ | Hold LT while receiving pass → immediately X | Faster release off the catch |
| **Floater/Runner** | Driving, R-Stick ↓ (release early) | Driving, R-Stick ↓ (release early) | Over shot blockers in paint |
| **Bank Shot** | R-Stick ↑ | R-Stick ↑ | Mid-range angles off glass |

### Pro Tips
- **Pro Stick vs Button:** Pro Stick (R-Stick ↓) gives you more control over timing and unlocks rhythm shots
- **Green Window:** Release at the peak of your jump animation — watch your player's hands
- **L2/LT Quick Shot:** Hold BEFORE you catch the ball for faster release
- **Post moves:** Always initiate with L2/LT to enter post stance first

## Dribble Moves for a 6'11" Center

At 6'11", your dribble options are very limited. You won't have access to guard dribble packages. Here's what matters:

### Available Dribble Styles (6'10"+)

| Style | Req (Ball Handle) | Notes |
|-------|-------------------|-------|
| Normal | 40 | Default, slow |
| Pro | 70 | Slightly better movement |
| Giannis Antetokounmpo | 55 | Best big man style — long strides, deceptive speed |
| Paolo Banchero | 50 | Good for stretch bigs |

**Recommendation:** Giannis dribble style if you have 55+ Ball Handle. It gives the longest strides and most deceptive movement for a big.

## Big Man Offensive Moves (No Dribble Required)

These are your bread and butter as a center:

### Post Moves (L2/LT to post up)

| Move | Control (PS5) | Control (Xbox) | When |
|------|---------------|----------------|------|
| **Drop Step** | Post up → R-Stick toward baseline | Post up → R-Stick toward baseline | Seal defender, go to rim |
| **Spin Move** | Post up → double-tap □ | Post up → double-tap X | Spin past defender |
| **Hop Step** | Post up → tap □ + direction | Post up → tap X + direction | Create space for shot |
| **Up-and-Under** | Post up → pump fake (△) → drive | Post up → pump fake (Y) → drive | Fake shot, go under |
| **Post Fade** | Post up → R-Stick away from basket | Post up → R-Stick away from basket | Fadeaway jumper |
| **Post Hook** | Post up → R-Stick toward basket (off-hand) | Post up → R-Stick toward basket | Hook shot |
| **Shimmy** | Post up → L-Stick left/right quickly | Post up → L-Stick left/right | Fake direction |

### Finishing at the Rim

| Move | Control (PS5) | Control (Xbox) | When |

## Your 6'11" Center Gameplan

### Offensive Priority Order:
1. **Grab rebound → Outlet pass** (HOF Break Starter triggers fast break)
2. **Set screens → Pop to 3PT line** (83 3PT, catch-and-shoot)
3. **Post up → Dirk fade / Kareem hook** (when matched up on smaller player)
4. **Cut to basket → Standing dunk / Alley-oop** (90 Standing Dunk)
5. **Putback dunks** after offensive rebounds

### Key Combos to Practice:
- **Pick-and-Pop:** Set screen (L1) → fade to corner → Quick Shot (L2 + □ on catch)
- **Post Fade:** L2 to post → back down → R-Stick away = Dirk one-leg fade
- **Outlet Fast Break:** Defensive rebound → hold △ toward open teammate = HOF Break Starter pass
- **Putback:** Crash boards → hold △ on offensive rebound = putback dunk
